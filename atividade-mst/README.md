# Atividade Prática 2 - Árvores Geradoras Mínimas

Implementação de busca de árvores geradoras mínimas utilizando os algoritmos de Prim e Kruskal. Executado via terminal com argparse.
 
## Como executar 

Kruskal:

python mst.py --input [ARQUIVO.txt] --alg kruskal

Prim:

python mst.py --input [ARQUIVO.txt] --alg prim --start [VERTICE]

- Existem três arquivos para testes dentro do .zip:
  - grafo1.txt
  - grafo2_empates.txt
  - grafo3_desconexo.txt
